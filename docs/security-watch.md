# 🛡️ Security Watch

Monitora advisories HIGH e CRITICAL relevantes ao stack PHP/Laravel, JavaScript e GitHub Actions usando a GitHub Advisory Database.

## Secret

`WEBHOOK_SECURITY`

## Horário

- 08:53 diariamente

O monitor cobre, entre outros, Laravel, Livewire, Symfony, Guzzle, PHPUnit, Pest, Vite, Axios, Tailwind e actions usadas nos workflows.

A primeira execução apenas inicializa `.state/security-watch.json`. Use `force_latest` no workflow manual para testar uma notificação.
